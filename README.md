# PPOTTO Client

- [Analytics 이벤트 목록](packages/bridge/src/analytics-events.ts) — 웹·네이티브 공용 이벤트 이름, 발생 시점, 파라미터 타입.
- [웹 개발 안내](apps/web/README.md)
- [모바일 개발 안내](apps/mobile/README.md)

로그인·온보딩·사진 선택/업로드·분석·보드 편집·리캡/공유·설정에 이벤트가 연결되어 있습니다.
웹뷰는 `@/shared/lib/bridge`, 네이티브는 `@/shared/lib/analytics`의 `track`을 사용합니다.

- 화면은 Stackflow 활성 노출 기준, 편집 성공은 서버 저장 성공 기준입니다. 자동 배치·반복 폴링은 세지 않습니다.
- 업로드/분석 시간은 이번 실행에서 관측한 구간만 보냅니다. 앱 재시작 전 시간·알 수 없는 사진 수/업로드 모드는 추측하지 않습니다. 클라이언트 관측 통계이므로 서버 작업 수와 일대일 대응하지 않습니다.
- 현재 Firebase 수집 경로는 **네이티브 앱과 앱 안의 웹뷰**입니다. 일반 브라우저·외부 공유 링크의 웹 방문 통계는 별도 웹 Analytics 연결이 필요합니다.
- 네이티브 자동 화면 기록을 껐으므로 `firebase.json` 반영을 위해 앱을 다시 빌드해야 합니다. 실제 기기에서 Firebase DebugView로 수신 여부를 확인하세요.
- 이메일·사진 URL·사용자 입력·오류 메시지 원문은 이벤트 파라미터에 넣지 않습니다.
