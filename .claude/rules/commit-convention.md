# 커밋 컨벤션

`gitmoji Type: 내용` 형식. Type은 대문자 시작, 내용은 한국어.

| Type     | gitmoji | 용도             |
| -------- | ------- | ---------------- |
| Feat     | ✨      | 기능 추가        |
| Fix      | 🐛      | 버그 수정        |
| Hotfix   | 🚑      | 긴급 수정        |
| Chore    | 🔧      | 설정, 잡일       |
| Deploy   | 🚀      | 배포             |
| Docs     | 📝      | 문서 작성/수정   |
| Style    | 💄      | 코드 포맷 변경   |
| Test     | ✅      | 테스트 추가/수정 |
| Refactor | ♻️      | 리팩토링         |
| Perf     | ⚡️      | 성능 개선        |

예: `✨ Feat: 갤러리 목록 화면 추가`, `🐛 Fix: 웹뷰 스크롤 튐 수정`
