# Next 이미지 부하 테스트 결과

2026-08-31에 CDN 없이 가비아 Next 테스트 서버를 측정한 기준선이다. 결과 비교에는 setup
요청이 섞인 `http_req_duration` 대신 `next_image_duration`을 사용했다.

## 환경

- 서버: 2 vCPU, RAM 3.8 GiB
- 런타임: Next.js 16.2.10, Node.js 22.22.3
- 요청: 보드 스티커 10개, 두 장씩 병렬, `w=750&q=75`
- 캐시: Next 로컬 디스크 캐시, CDN 없음

## 결론

- Cold는 5 VU 이후 처리량 증가 없이 지연만 커져 이미지 변환 연산이 먼저 포화됐다.
- Warm은 100 VU까지 잘 확장됐고, 이후 증가 효율이 낮아졌다.
- Warm 300 VU에서 약 1,560 req/s, 70 MB/s 부근의 전송 상한을 보였다.
- 모든 실행에서 이미지 오류는 없었다.

## 주의사항

- 위 Cold 결과는 호출마다 다른 signed URL이 발급되던 시점의 기록이다. signed URL 재사용
  적용 이후의 Cold 결과와 직접 비교하면 안 된다.
- 2026-09-01 가비아 Local CDN은 `url`, `w`, `q`를 캐시 키로 구분하지 않아 서로 다른
  요청에 같은 이미지를 반환했다. 해당 CDN 결과는 표에서 제외했다.
- 리캡 사진과 CDN은 원본 종류, 이미지 width, 판정 헤더가 다르므로 별도 시나리오로 측정한다.
